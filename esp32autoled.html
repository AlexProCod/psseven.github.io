Автоматическая система управления освещением

Система будет автоматически включать освещение при обнаружении движения в помещении и регулировать яркость света в зависимости от уровня естественного освещения. Также можно добавить возможность удаленного управления через мобильное приложение.

Необходимые компоненты

  • Микроконтроллер ESP32 или Arduino — встроенный Wi-Fi позволит легко интегрировать систему с облачными сервисами
  • Датчик движения (PIR-сенсор) — для обнаружения движения в помещении
  • Датчик освещенности (например, фотодатчик или TSL2561) — для измерения уровня освещенности
  • Реле или MOSFET — для управления включением и выключением лампы
  • Светодиодная лампа или любая другая лампа — для освещения
  • Мобильное приложение или веб-интерфейс — для удаленного управления и мониторинга
💡Совет: ESP32 предпочтительнее для этого проекта благодаря встроенному Wi-Fi/Bluetooth и большему количеству аналоговых входов по сравнению с Arduino Uno.

Шаги реализации

  1. Сборка аппаратной части:
    • Подключите PIR-сенсор и датчик освещенности к микроконтроллеру
    • Подключите лампу через реле или MOSFET к микроконтроллеру для управления питанием лампы
    • Обеспечьте надёжное питание всех компонентов (особенно реле)
  2. Программирование микроконтроллера:
    • Напишите код на Arduino IDE или MicroPython для считывания данных с датчиков
    • Реализуйте логику включения и выключения лампы на основе данных с датчиков движения и освещенности
    • Добавьте гистерезис для предотвращения частого переключения при пограничных значениях
  3. Создание мобильного приложения или веб-интерфейса:
    • Используйте Blynk или аналогичные платформы для создания мобильного приложения, которое позволит удаленно управлять системой освещения
    • Настройте передачу данных от микроконтроллера к мобильному приложению через Wi-Fi
    • Добавьте виджеты для отображения состояния датчиков и ручного управления
  4. Тестирование и настройка:
    • Тестируйте систему в различных условиях освещенности и активности, чтобы убедиться в корректной работе
    • Настройте чувствительность датчиков и пороговые значения для включения и выключения света
    • Проверьте работу системы при потере связи с приложением (автономный режим)

Схема подключения к ESP32

  1. PIR-датчик движения:
    • VCC → 5V или 3.3V (зависит от модели)
    • GND → GND
    • OUT → GPIO 27 (цифровой вход)
  2. Датчик освещенности TSL2561 (I2C):
    • VCC → 3.3V
    • GND → GND
    • SCL → GPIO 22
    • SDA → GPIO 21
  3. Релейный модуль:
    • VCC → 5V
    • GND → GND
    • IN → GPIO 26 (управление реле)
  4. Лампа:
    • Подключается через нормально разомкнутые контакты реле
    • ⚠️ При работе с сетевым напряжением 220В соблюдайте технику безопасности!
⚠️Предупреждение: При подключении лампы к сети 220В через реле обязательно изолируйте высоковольтную часть и используйте корпус. Не работайте с подключённым сетевым напряжением без соответствующих навыков!

Пример кода для управления освещением

Код на Arduino IDE для ESP32 с использованием датчиков PIR, TSL2561 и платформы Blynk для удалённого управления:

#include <WiFi.h>
#include <BlynkSimpleEsp32.h>
#include <Wire.h>
#include <Adafruit_Sensor.h>
#include <Adafruit_TSL2561_U.h>

// Инициализация датчика освещенности
Adafruit_TSL2561_Unified tsl = Adafruit_TSL2561_Unified(TSL2561_ADDR_FLOAT, 12345);

// Инициализация PIR-сенсора
const int pirPin = 27; // Пин, к которому подключен PIR-сенсор
const int relayPin = 26; // Пин, к которому подключено реле

// Инициализация Blynk
char auth[] = "YourAuthToken";
char ssid[] = "YourNetworkName";
char pass[] = "YourPassword";

// Пороговые значения
const float LIGHT_THRESHOLD = 50; // Люксы - порог включения света
unsigned long lastMotionTime = 0;
const unsigned long MOTION_TIMEOUT = 30000; // 30 секунд после последнего движения

void setup() {
  Serial.begin(115200);

  pinMode(pirPin, INPUT);
  pinMode(relayPin, OUTPUT);
  digitalWrite(relayPin, LOW); // Свет выключен по умолчанию

  Blynk.begin(auth, ssid, pass);

  if (!tsl.begin()) {
    Serial.print("No TSL2561 detected");
    while (1);
  }
  tsl.enableAutoRange(true);
  tsl.setIntegrationTime(TSL2561_INTEGRATIONTIME_13MS);
}

void loop() {
  Blynk.run();

  sensors_event_t event;
  tsl.getEvent(&event);

  int pirState = digitalRead(pirPin);
  
  // Логика управления освещением
  if (pirState == HIGH) {
    lastMotionTime = millis(); // Запоминаем время последнего движения
  }
  
  // Включаем свет если: темно И (есть движение ИЛИ прошло меньше таймаута с последнего движения)
  bool shouldTurnOn = (event.light < LIGHT_THRESHOLD) && 
                      (pirState == HIGH || (millis() - lastMotionTime < MOTION_TIMEOUT));
  
  digitalWrite(relayPin, shouldTurnOn ? HIGH : LOW);

  // Отправка данных в Blynk для мониторинга
  Blynk.virtualWrite(V1, event.light);    // Уровень освещенности
  Blynk.virtualWrite(V2, pirState);       // Состояние PIR
  Blynk.virtualWrite(V3, shouldTurnOn);   // Состояние реле

  delay(1000);
}
ℹ️Примечание: Замените YourAuthToken, YourNetworkName и YourPassword на ваши реальные данные. Токен авторизации можно получить в приложении Blynk после создания нового проекта.

Настройка Blynk для удалённого управления

  1. Установите приложение Blynk на смартфон и создайте новый проект для ESP32
  2. Добавьте виджеты:
    • Value Display для отображения уровня освещенности (привязать к V1)
    • Led для индикации обнаружения движения (привязать к V2)
    • Button для ручного управления светом (привязать к V3)
  3. В коде добавьте обработчик для кнопки ручного управления: 
    BLYNK_WRITE(V3) {
  int state = param.asInt();
  digitalWrite(relayPin, state);
}
  4. Загрузите код в ESP32 и запустите проект в приложении Blynk

Возможные проблемы и решения

  • PIR-датчик не обнаруживает движение:
    • Проверьте питание датчика (некоторые модели требуют 5В)
    • Отрегулируйте потенциометры чувствительности и времени задержки на датчике
    • Убедитесь, что датчик направлен в нужную зону и не закрыт препятствиями
  • Датчик TSL2561 не определяется:
    • Проверьте подключение SDA/SCL и наличие подтягивающих резисторов 4.7 кОм
    • Убедитесь, что адрес датчика совпадает с указанным в коде (TSL2561_ADDR_FLOAT, _LOW или _HIGH)
    • Проверьте, не заняты ли пины 21/22 другими устройствами
  • Реле щёлкает, но лампа не включается:
    • Проверьте подключение лампы к правильным контактам реле (NO — нормально разомкнутые)
    • Убедитесь, что лампа исправна и есть напряжение в сети
    • Проверьте, выдерживает ли реле ток вашей лампы (особенно для светодиодных с драйверами)
  • ESP32 теряет соединение с Blynk:
    • Добавьте переподключение при потере Wi-Fi в коде
    • Используйте WDT (Watchdog Timer) для автоматической перезагрузки при зависании
    • Проверьте стабильность питания (добавьте конденсатор 100–470 мкФ)

Идеи для расширения функционала

  • Плавное регулирование яркости: Замените реле на MOSFET и используйте ШИМ для диммирования светодиодной ленты
  • Расписание работы: Добавьте библиотеку time.h для включения света только в определённые часы
  • Интеграция с голосовыми помощниками: Используйте платформы типа IFTTT или Home Assistant для управления через Alexa/Google Home
  • Энергостатистика: Добавьте модуль измерения тока (например, ACS712) для учёта потребления энергии
  • Локальное управление: Добавьте кнопку для ручного включения/выключения без зависимости от Wi-Fi
🚀Идея: Объедините эту систему с датчиком присутствия и календарём отпусков — свет будет включаться только когда вы дома, экономя электроэнергию!
