Монитор состояния дверей с уведомлениями Telegram на ESP8266 NodeMCU

В этом проекте вы будете отслеживать открывание двери с помощью ESP8266 NodeMCU и магнитного геркона. Вы будете получать сообщение в своей учетной записи Telegram всякий раз, когда дверь меняет состояние: открыта или закрыта. Пока у вас есть доступ к Интернету на вашем смартфоне, вы будете получать уведомления, где бы вы ни находились. Плата ESP8266 будет запрограммирована с использованием Arduino IDE.

Магнитный контактный переключатель — это, по сути, геркон, заключенный в пластиковый корпус, поэтому вы можете легко прикрепить его к двери, окну или ящику, чтобы определить, открыта она или закрыта.

Электрическая цепь замыкается, когда магнит находится рядом с выключателем — дверь закрыта. Когда магнит находится далеко от выключателя – дверь открыта – цепь разомкнута.

Мы будем программировать плату ESP8266 с использованием Arduino IDE, поэтому убедитесь, что она установлена в вашей Arduino IDE.

Универсальная библиотека ботов Telegram

Для взаимодействия с ботом Telegram мы будем использовать универсальную библиотеку ботов Telegram, созданную Брайаном Лофом, которая обеспечивает простой интерфейс для API бота Telegram.

Выполните следующие шаги, чтобы установить последнюю версию библиотеки:

  1. Нажмите здесь, чтобы загрузить библиотеку Universal Arduino Telegram Bot.
  2. Перейдите в «Скетч» → «Включить библиотеку» → «Добавить .ZIP-библиотеку».
  3. Добавьте библиотеку, которую вы только что скачали.
❗Важно: не устанавливайте библиотеку через диспетчер библиотек Arduino, поскольку это может привести к установке устаревшей версии.

Все подробности о библиотеке можно найти на странице GitHub Universal Arduino Telegram Bot Library.

Библиотека ArduinoJson

Вам также необходимо установить библиотеку ArduinoJson. Выполните следующие шаги:

  1. Перейдите в Sketch → Include Library → Manage Libraries.
  2. Найдите «ArduinoJson».
  3. Установите библиотеку.

Мы используем библиотеку ArduinoJson версии 6.15.2.

Схема подключения

Мы подключили геркон к GPIO 4 (D2), но подключить его можно к любому подходящему GPIO.

💡Подсказка: GPIO 4 на NodeMCU соответствует пину D2.

Пример кода

Скопируйте приведённый ниже эскиз в вашу Arduino IDE. Замените SSID, пароль, токен BOT и идентификатор пользователя своими учетными данными.

#include <ESP8266WiFi.h>
#include <WiFiClientSecure.h>
#include <UniversalTelegramBot.h>
#include <ArduinoJson.h>

// Установите GPIO для светодиода и геркона
const int reedSwitch = 4;
const int led = 2; //optional

// Обнаруживает всякий раз, когда дверь меняет состояние
bool changeState = false;

// Удерживает состояние геркона (1=открыто, 0=закрыто)
bool state;
String doorState;

// Вспомогательные переменные
unsigned long previousMillis = 0;
const long interval = 1500;

const char* ssid = "REPLACE_WITH_YOUR_SSID";
const char* password = "REPLACE_WITH_YOUR_PASSWORD";

// Initialize Telegram BOT
#define BOTtoken "XXXXXXXXXX:XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"  // ваш токен бота (получите от Botfather)

// Используйте @myidbot, чтобы узнать идентификатор чата отдельного человека или группы.
// Также обратите внимание, что вам нужно нажать «старт» на боте, прежде чем он сможет отправлять вам сообщения
#define CHAT_ID "XXXXXXXXXX"

X509List cert(TELEGRAM_CERTIFICATE_ROOT);
WiFiClientSecure client;
UniversalTelegramBot bot(BOTtoken, client);

// Запускается всякий раз, когда геркон меняет состояние.
ICACHE_RAM_ATTR void changeDoorStatus() {
  Serial.println("State changed");
  changeState = true;
}

void setup() {
  // Последовательный порт для отладки
  Serial.begin(115200);
  configTime(0, 0, "pool.ntp.org");      // получить время UTC через NTP
  client.setTrustAnchors(&cert);  // Добавить корневой сертификат для api.telegram.org

  // Определяем текущее состояние двери
  pinMode(reedSwitch, INPUT_PULLUP);
  state = digitalRead(reedSwitch);

  // Устанавливаем состояние светодиода в соответствии с состоянием двери
  pinMode(led, OUTPUT);
  digitalWrite(led, state);

  // Установим контакт геркона в разомкнутое состояние, назначим функцию прерывания и установим режим CHANGE.
  attachInterrupt(digitalPinToInterrupt(reedSwitch), changeDoorStatus, CHANGE);

  // Подключение к Wi-Fi
  WiFi.mode(WIFI_STA);
  WiFi.begin(ssid, password);  // Пишем название точки доступа и пароль для подключения
    while (WiFi.status() != WL_CONNECTED) {
      delay(500);
      Serial.print(".");
    }
    Serial.println("");
    Serial.println("WiFi connected");

    bot.sendMessage(CHAT_ID, "Bot started up", "");
}

void loop() {
  if (changeState){
    unsigned long currentMillis = millis();
    if(currentMillis - previousMillis >= interval) {
      previousMillis = currentMillis;
      // Если изменение произошло, инвертируем текущее состояние двери.
        state = !state;
        if(state) {
          doorState = "closed";
        }
        else{
          doorState = "open";
        }
        digitalWrite(led, state);
        changeState = false;
        Serial.println(state);
        Serial.println(doorState);

        //Send notification
        bot.sendMessage(CHAT_ID, "The door is " + doorState, "");
    }
  }
}

Загрузка и тестирование

После изменения эскиза, включив в него ваши сетевые учетные данные, токен бота и идентификатор пользователя, загрузите его на свой ESP8266:

  1. Перейдите в «Инструменты» → «Плата» и выберите плату ESP8266.
  2. Затем перейдите в «Инструменты» → «Порт» и выберите COM-порт, к которому подключен ESP8266.
  3. Откройте последовательный монитор на скорости передачи 115200 бод, чтобы проверить, обнаружены ли изменения.

Для создания прототипа/тестирования вы можете прикрепить магнитный геркон к двери с помощью липучки.

✅Результат: Теперь, когда кто-то открывает/закрывает вашу дверь, вы получаете сообщение в своем аккаунте Telegram.

Возможные проблемы и решения

  • Бот не отправляет сообщения:
    • Проверьте правильность токена бота и CHAT_ID.
    • Убедитесь, что вы нажали «Start» в диалоге с ботом в Telegram.
    • Проверьте подключение к интернету на ESP8266.
  • Геркон не срабатывает:
    • Проверьте подключение пина к GPIO и наличие INPUT_PULLUP.
    • Убедитесь, что магнит находится достаточно близко к геркону в закрытом состоянии.
  • ESP8266 перезагружается:
    • Проверьте стабильность питания (рекомендуется 5В через VIN).
    • Добавьте конденсатор 10–100 мкФ между VCC и GND рядом с платой.
