Система слежения за автомобилем на ESP32

Этот проект представляет собой систему слежения за автомобилем на базе ESP32, которая использует GPS-модуль для отслеживания местоположения автомобиля и отправляет данные на сервер или мобильное приложение через сотовую связь с использованием GPRS или Wi-Fi. Система может быть полезной для мониторинга автомобиля, его нахождения в случае кражи, а также для других задач, таких как контроль маршрутов.

Компоненты и оборудование

  • ESP32 — основной микроконтроллер с встроенным Wi-Fi/Bluetooth
  • GPS модуль (NEO-6M или NEO-M8N) — для определения точных координат автомобиля
  • GPRS/3G/4G модем (SIM800L или SIM900) — для передачи данных через сотовую сеть
  • Аккумулятор (Li-Po) — для автономной работы устройства в автомобиле
  • Кнопка включения/выключения — для активации или деактивации системы
  • Датчик питания (MOSFET-модуль) — для контроля и управления питанием
  • Провода и кабели — для надёжного подключения всех компонентов
💡Совет: Модуль NEO-M8N обеспечивает более быстрое получение фиксированных координат и лучшую чувствительность по сравнению с NEO-6M — рекомендуем его для автомобильных применений.

Схема подключения компонентов

  1. GPS модуль (NEO-6M/NEO-M8N) через UART:
    • VCC → 3.3V или 5V (зависит от модели)
    • GND → GND
    • TX → GPIO 4 (RX ESP32)
    • RX → GPIO 5 (TX ESP32)
  2. GPRS модем (SIM800L) через UART:
    • VCC → 4.0–4.2V (требует стабильного питания!)
    • GND → GND (общий с ESP32)
    • TX → GPIO 16 (RX ESP32)
    • RX → GPIO 17 (TX ESP32, через делитель 3.3В)
    • PWRKEY → GPIO 9 (для включения/выключения модема)
    • RST → GPIO 8 (опционально, для перезагрузки)
  3. Кнопка включения:
    • Один контакт → GND
    • Другой контакт → GPIO 12 и через резистор 10 кОм к 3.3В
  4. Питание:
    • Li-Po аккумулятор → через DC-DC преобразователь к 5В/3.3В шине
    • Добавьте конденсатор 1000 мкФ рядом с SIM800L для компенсации пиков тока
⚠️Важно: Модуль SIM800L потребляет до 2А в пике при передаче данных — используйте качественный источник питания и толстые провода, иначе модем будет перезагружаться.

Установка необходимых библиотек

  1. Откройте Arduino IDE
  2. Перейдите в Скетч → Подключить библиотеку → Управление библиотеками
  3. Установите следующие библиотеки:
    • TinyGPS++ — для парсинга NMEA-данных с GPS
    • Adafruit FONA — для работы с модулями SIM800/SIM900
    • SoftwareSerial — для создания дополнительных UART-портов (если не используете аппаратные)
ℹ️Примечание: На ESP32 предпочтительнее использовать аппаратные UART (Serial1, Serial2), так как SoftwareSerial может работать нестабильно на высоких скоростях.

Код для ESP32

Скопируйте приведённый ниже код в Arduino IDE. Замените your_APN, your_PIN и your_server_URL на ваши реальные данные.

#include <TinyGPS++.h>
#include <HardwareSerial.h>
#include <Adafruit_FONA.h>

// ========== НАСТРОЙКИ ==========
// Пины для GPS модуля (UART2)
#define GPS_RX 4
#define GPS_TX 5

// Пины для GPRS модуля (UART1)
#define FONA_RX 16
#define FONA_TX 17
#define FONA_RST 8
#define FONA_PWRKEY 9

// Настройки SIM-карты
#define FONA_PIN "1234"           // PIN-код вашей SIM-карты (если есть)
#define APN "internet"            // APN вашего оператора (МТС: internet.mts.ru)

// Сервер для отправки данных
const char* serverURL = "http://yourserver.com/update";

// Кнопка включения системы
const int buttonPin = 12;

// ========== ОБЪЕКТЫ ==========
TinyGPSPlus gps;
HardwareSerial gpsSerial(2);      // UART2 для GPS
HardwareSerial fonaSerial(1);     // UART1 для GPRS
Adafruit_FONA fona = Adafruit_FONA(FONA_RST);

bool systemActive = false;
unsigned long lastSend = 0;
const unsigned long sendInterval = 60000; // Отправка каждые 60 секунд

void setup() {
  Serial.begin(115200);
  
  // Инициализация UART для GPS
  gpsSerial.begin(9600, SERIAL_8N1, GPS_RX, GPS_TX);
  
  // Инициализация UART для GPRS
  fonaSerial.begin(9600, SERIAL_8N1, FONA_RX, FONA_TX);
  
  // Инициализация кнопки
  pinMode(buttonPin, INPUT_PULLUP);
  
  // Инициализация FONA модуля
  Serial.println(F("Инициализация GPRS модуля..."));
  if (!fona.begin(fonaSerial)) {
    Serial.println(F("❌ Не удалось подключиться к модему"));
    while (1);
  }
  Serial.println(F("✅ Модем подключён"));
  
  // Ввод PIN-кода (если требуется)
  if (strlen(FONA_PIN) > 0) {
    fona.enablePIN(FONA_PIN);
  }
  
  // Настройка GPRS
  fona.setGPRSNetworkSettings(APN);
  
  Serial.println(F("Система готова. Нажмите кнопку для старта."));
}

void loop() {
  // Обработка кнопки (активное низкое состояние)
  if (digitalRead(buttonPin) == LOW) {
    systemActive = !systemActive;
    Serial.println(systemActive ? F("🔵 Система АКТИВИРОВАНА") : F("🔴 Система ДЕЗАКТИВИРОВАНА"));
    delay(500); // Защита от дребезга
  }
  
  // Если система активна — обрабатываем GPS и отправляем данные
  if (systemActive) {
    // Чтение данных с GPS
    while (gpsSerial.available() > 0) {
      gps.encode(gpsSerial.read());
    }
    
    // Если координаты обновились и прошло время с последней отправки
    if (gps.location.isUpdated() && (millis() - lastSend >= sendInterval)) {
      double lat = gps.location.lat();
      double lng = gps.location.lng();
      float speed = gps.speed.kmph();
      uint32_t satellites = gps.satellites.value();
      
      Serial.printf("📍 Координаты: %.6f, %.6f | Скорость: %.1f км/ч | Спутники: %d\n", 
                    lat, lng, speed, satellites);
      
      // Отправка на сервер
      if (sendLocationToServer(lat, lng, speed)) {
        lastSend = millis();
        Serial.println(F("✅ Данные отправлены"));
      } else {
        Serial.println(F("❌ Ошибка отправки"));
      }
    }
  }
  
  delay(100);
}

// Функция отправки данных на сервер через HTTP POST
bool sendLocationToServer(double latitude, double longitude, float speed) {
  // Формируем тело запроса
  String postData = "lat=" + String(latitude, 6) + 
                    "&lon=" + String(longitude, 6) + 
                    "&speed=" + String(speed, 1);
  
  // Отправляем HTTP POST запрос
  uint16_t statuscode;
  int16_t length;
  
  if (!fona.HTTP_POST_start(serverURL, F("application/x-www-form-urlencoded"), 
                           (uint8_t *)postData.c_str(), postData.length(), 
                           &statuscode, (uint16_t *)&length)) {
    return false;
  }
  
  fona.HTTP_POST_end();
  return (statuscode == 200);
}

Пояснение к коду

  1. Инициализация UART: Используем два аппаратных UART-порта: UART2 для GPS (9600 бод) и UART1 для GPRS-модема
  2. Обработка кнопки: Система активируется/деактивируется нажатием кнопки на GPIO 12 (с подтяжкой к 3.3В)
  3. Чтение GPS: Библиотека TinyGPS++ парсит NMEA-строки и предоставляет готовые координаты, скорость, количество спутников
  4. Отправка данных: Данные отправляются на сервер каждые 60 секунд через HTTP POST запрос с использованием FONA-библиотеки
  5. Защита от частой отправки: Переменная lastSend предотвращает перегрузку сети и экономию трафика
🔧Совет: Для отладки используйте монитор последовательного порта (115200 бод) — там выводятся все координаты и статусы отправки.

Тестирование и оптимизация

  1. Проверка GPS:
    • Разместите антенну GPS на открытом месте (не в металлическом корпусе)
    • Дождитесь получения фиксированных координат (может занять 1–5 минут)
    • Проверьте количество спутников в мониторе порта (минимум 4 для 3D-фиксации)
  2. Проверка GPRS:
    • Убедитесь, что SIM-карта активна и имеет баланс/трафик
    • Проверьте правильность APN для вашего оператора
    • Протестируйте отправку данных на тестовый сервер (например, httpbin.org/post)
  3. Оптимизация энергопотребления:
    • Используйте deep sleep ESP32 между отправлениями данных
    • Отключайте GPS-модуль через пин VCC_EN при неактивности
    • Настройте интервал отправки в зависимости от задачи (1–10 минут)

Возможные проблемы и решения

  • GPS не находит спутники:
    • Разместите антенну на крыше автомобиля или у окна
    • Проверьте подключение антенны к модулю (разъём U.FL)
    • Убедитесь, что модуль не экранирован металлическим корпусом
  • SIM800L не подключается к сети:
    • Проверьте питание: напряжение должно быть 4.0–4.2В, ток до 2А
    • Убедитесь, что SIM-карта разблокирована и не требует PUK
    • Проверьте уровень сигнала командой AT+CSQ (значение >10 желательно)
  • Данные не доходят до сервера:
    • Проверьте URL сервера и метод запроса (POST/GET)
    • Убедитесь, что сервер принимает запросы с мобильного IP
    • Добавьте логирование ответа сервера в код для отладки
  • ESP32 перезагружается:
    • Добавьте конденсатор 1000 мкФ параллельно питанию SIM800L
    • Используйте отдельный стабилизатор 3.3В для ESP32
    • Проверьте, не перегружен ли вывод 3.3В на плате

Идеи для расширения функционала

  • Геозоны: Настройте уведомления при въезде/выезде из заданной области
  • Датчик зажигания: Подключите вход к цепи зажигания для отслеживания работы двигателя
  • Акселерометр: Добавьте MPU6050 для обнаружения ударов и эвакуации автомобиля
  • Telegram-уведомления: Отправляйте координаты в чат при срабатывании тревоги
  • Веб-карта: Интегрируйте с Leaflet/Google Maps для визуализации маршрута в реальном времени
  • Резервное копирование: Сохраняйте координаты на microSD при потере связи с сервером
🚀Идея: Объедините систему с датчиком наклона и микрофоном — при попытке эвакуации или разбития стекла система отправит координаты и включит запись звука!
