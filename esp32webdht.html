Веб-сервер температуры и влажности на ESP32 и DHT11/DHT22

В этой статье вы узнаете, как создать асинхронный веб-сервер ESP32 с DHT11 или DHT22, который отображает температуру и влажность с помощью Arduino IDE.

Веб-сервер, который мы создадим, будет обновлять показания автоматически, без необходимости обновления веб-страницы.

Для создания веб-сервера мы будем использовать библиотеку ESPAsyncWebServer, которая обеспечивает простой способ создания асинхронного веб-сервера. Создание асинхронного веб-сервера имеет несколько преимуществ:

  • Обрабатывать более одного соединения одновременно
  • Когда вы отправляете ответ, вы немедленно готовы обрабатывать другие соединения, в то время как сервер занимается отправкой ответа в фоновом режиме
  • Простой механизм обработки шаблонов для работы с шаблонами
💡Документация: Ознакомьтесь с документацией библиотеки на её странице GitHub.

Схема подключения

Прежде чем перейти к веб-серверу, необходимо подключить датчик DHT11 или DHT22 к ESP32. В этом случае мы подключаем контакт данных к GPIO 27, но вы можете подключить его к любому другому цифровому пину.

ℹ️Примечание: Если вы используете модуль с датчиком DHT, он обычно поставляется только с тремя контактами. Контакты должны быть помечены, чтобы вы знали, как их подключать. Кроме того, многие из этих модулей уже поставляются с внутренним подтягивающим резистором, поэтому вам не нужно добавлять его в схему.

Необходимые библиотеки

Для этого проекта вам необходимо установить следующие библиотеки:

  • DHT sensor library и Adafruit Unified Sensor Driver — для чтения данных с датчика DHT
  • ESPAsyncWebServer и AsyncTCP — для создания асинхронного веб-сервера
❗Важно: Мы будем программировать ESP32 с помощью Arduino IDE, поэтому перед продолжением убедитесь, что у вас установлено дополнение ESP32.

Код веб-сервера

Откройте Arduino IDE и скопируйте следующий код. Не забудьте заменить REPLACE_WITH_YOUR_SSID и REPLACE_WITH_YOUR_PASSWORD на данные вашей сети Wi-Fi.

#include "WiFi.h"
#include "ESPAsyncWebServer.h"
#include <Adafruit_Sensor.h>
#include <DHT.h>

// Укажите название и пароль для доступа к вашему wifi
const char* ssid = "REPLACE_WITH_YOUR_SSID";
const char* password = "REPLACE_WITH_YOUR_PASSWORD";

#define DHTPIN 27     // Цифровой контакт, подключенный к датчику DHT

// Раскомментируйте тип используемого датчика:
//#define DHTTYPE    DHT11     // DHT 11
#define DHTTYPE    DHT22     // DHT 22 (AM2302)
//#define DHTTYPE    DHT21     // DHT 21 (AM2301)

DHT dht(DHTPIN, DHTTYPE);

// Создаем объект AsyncWebServer на порту 80
AsyncWebServer server(80);

String readDHTTemperature() {
  // Считываем температуру в градусах Цельсия (по умолчанию)
  float t = dht.readTemperature();
  // Read temperature as Fahrenheit (isFahrenheit = true)
  //float t = dht.readTemperature(true);
  // Check if any reads failed and exit early (to try again).
  if (isnan(t)) {
    Serial.println("Failed to read from DHT sensor!");
    return "--";
  }
  else {
    Serial.println(t);
    return String(t);
  }
}

String readDHTHumidity() {
  float h = dht.readHumidity();
  if (isnan(h)) {
    Serial.println("Failed to read from DHT sensor!");
    return "--";
  }
  else {
    Serial.println(h);
    return String(h);
  }
}

// Заменяем строку значениями DHT.
String processor(const String& var){
  //Serial.println(var);
  if(var == "TEMPERATURE"){
    return readDHTTemperature();
  }
  else if(var == "HUMIDITY"){
    return readDHTHumidity();
  }
  return String();
}

void setup(){
  // Последовательный порт для целей отладки
  Serial.begin(115200);

  dht.begin();

  // Подключение к Wi-Fi
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(1000);
    Serial.println("Connecting to WiFi..");
  }

  // Вывод ESP32 IP адрес
  Serial.println(WiFi.localIP());

  // Маршрут для корневой/веб-страницы
  server.on("/", HTTP_GET, {
    request->send_P(200, "text/html", index_html, processor);
  });
  server.on("/temperature", HTTP_GET, {
    request->send_P(200, "text/plain", readDHTTemperature().c_str());
  });
  server.on("/humidity", HTTP_GET, {
    request->send_P(200, "text/plain", readDHTHumidity().c_str());
  });

  // Start server
  server.begin();
}

Загрузка и тестирование

  1. Замените ssid и password на данные вашей сети Wi-Fi
  2. Раскомментируйте нужный тип датчика: DHT11, DHT22 или DHT21
  3. Выберите плату: Инструменты → Плата → ESP32 Dev Module
  4. Выберите порт и загрузите скетч на ESP32
  5. Откройте монитор последовательного порта (115200 бод) и дождитесь появления IP-адреса
  6. Введите этот IP-адрес в браузере — вы увидите страницу с температурой и влажностью
  7. Показания будут автоматически обновляться каждые 10 секунд без перезагрузки страницы
🔧Совет: Если датчик не читает данные:
  • Проверьте подключение контакта DATA к правильному GPIO
  • Убедитесь, что выбран правильный тип датчика в коде
  • Добавьте подтягивающий резистор 10 кОм между DATA и VCC, если модуль его не имеет
  • Проверьте питание датчика (3.3В или 5В в зависимости от модели)

Возможные проблемы и решения

  • Показания "--" или не обновляются:
    • Проверьте надёжность подключения проводов к датчику
    • Убедитесь, что датчик не находится рядом с источниками тепла
    • Добавьте задержку 2 секунды между чтениями датчика (требование DHT)
  • Веб-страница не загружается:
    • Убедитесь, что устройство подключено к той же сети 2.4 ГГц
    • Проверьте корректность ввода пароля (чувствительно к регистру)
    • Попробуйте ввести IP-адрес вручную, а не через поиск
  • ESP32 перезагружается:
    • Добавьте конденсатор 10–100 мкФ между 3.3В и GND рядом с платой
    • Используйте стабильный источник питания 5В/2А
    • Проверьте, не перегружен ли вывод питания 3.3В
