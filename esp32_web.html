Управляем выходами через веб-сервер на ESP32

В Интернете все веб-сайты размещаются на компьютере, и этот компьютер называется сервером. Поскольку этот конкретный сервер используется для обслуживания веб-страниц и веб-запросов, мы называем его веб-сервером. Вместо использования компьютера мы также можем использовать ESP32 для ответа на веб-запросы, благодаря встроенному WiFi ESP32. ESP32 может не только отвечать на запросы, но и обслуживать небольшие веб-страницы, которые либо были жестко закодированы в коде, либо хранились во флэш-памяти.

В этой статье мы рассмотрим, как создать веб-сервер на ESP32 с нуля. Мы рассмотрим шаги по настройке ESP32, подключению светодиодов и созданию веб-интерфейса для управления ими. Независимо от того, являетесь ли вы опытным или только начинаете работать с проектами IoT, это руководство поможет вам вывести свои навыки на новый уровень.

💡Краткий обзор: Включение/выключение светодиода с помощью веб-сервера ESP32:
  • Подключение светодиодов к GPIO12 и GPIO14 на ESP32
  • Ввод IP-адреса ESP32 в браузере для доступа к странице управления
  • Нажатие кнопок на веб-странице для управления светодиодами

Необходимые компоненты

  1. Плата разработки ESP32 — основной компонент для управления светодиодными лампами через веб-сервер
  2. Светодиодные лампы — для этого проекта использовались 2× 5 мм светодиода
  3. Макетная плата — для подключения светодиодов к микроконтроллеру
  4. Провода-перемычки — для соединения макетной платы, ESP32 и светодиодов
  5. USB-кабель — для подключения ESP32 к компьютеру для программирования
  6. Компьютер — для программирования и загрузки кода
  7. Резистор 220 Ом — для ограничения тока через светодиоды и предотвращения их перегорания

Схема подключения

Микроконтроллер ESP32 имеет много контактов GPIO, которые можно использовать для взаимодействия с внешними устройствами, такими как светодиодные фонари. В этом примере мы подключим ESP32 к двум светодиодам, подключенным к контактам GPIO 12 и 14.

  1. Подключите один конец резистора 220 Ом к контакту GPIO 12 на ESP32, а другой конец — к положительному (аноду) выводу первого светодиода
  2. Подключите отрицательную (катодную) ножку светодиода к GND на ESP32
  3. Повторите шаги 1 и 2 для контакта GPIO 14 и второго светодиода
ℹ️Примечание: Для этих же целей вы также можете использовать веб-сервер ESP32 Ethernet. В этом случае вам понадобится плата Ethernet Shield для ESP32 и небольшие изменения в коде.

Библиотеки

Вам не нужно устанавливать какую-либо специальную библиотеку для использования веб-сервера, поскольку библиотека веб-сервера ESP32 является частью ядра ESP32 Arduino. Существует множество примеров веб-сервера ESP32, которые поставляются с библиотекой — вы можете ознакомиться с ними через меню Файл → Примеры → ESP32 → WebServer в Arduino IDE.

Код веб-сервера для управления выходами

❗Важно: Перед загрузкой кода обязательно измените сетевые учетные данные (ssid и password) на свои. 
// Загрузка библиотеки Wi-Fi
#include <WiFi.h>

// Замените на ваши сетевые учетные данные
const char* ssid = "REPLACE_WITH_YOUR_SSID";
const char* password = "REPLACE_WITH_YOUR_PASSWORD";

// Установите номер порта веб-сервера на 80
WiFiServer server(80);

// Переменная для хранения заголовка HTTP-запроса
String header;

// Вспомогательные переменные для хранения текущего состояния вывода
String output12State = "off";
String output14State = "off";

// Назначьте выходные переменные контактам GPIO
const int output12 = 12;
const int output14 = 14;

// Текущее время
unsigned long currentTime = millis();
// Предыдущее время
unsigned long previousTime = 0;
// Определите время ожидания в миллисекундах (пример: 2000 мс = 2 с)
const long timeoutTime = 2000;

void setup() {
  Serial.begin(115200);
  
  // Инициализируем выходные переменные как выходные
  pinMode(output12, OUTPUT);
  pinMode(output14, OUTPUT);
  
  // Устанавливаем выходные значения в LOW
  digitalWrite(output12, LOW);
  digitalWrite(output14, LOW);
  
  // Подключаемся к сети Wi-Fi с помощью SSID и пароля
  Serial.print("Connecting to ");
  Serial.println(ssid);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  
  // Вывод локального IP-адреса и запуск веб-сервера
  Serial.println("");
  Serial.println("WiFi connected.");
  Serial.println("IP address: ");
  Serial.println(WiFi.localIP());
  server.begin();
}

void loop(){
  WiFiClient client = server.available();   // Прослушивание входящих клиентов
  
  if (client) {                             // Если подключается новый клиент
    currentTime = millis();
    previousTime = currentTime;
    Serial.println("New Client.");          // вывод сообщения в последовательный порт
    
    String currentLine = "";                // строка для хранения входящих данных
    while (client.connected() && currentTime - previousTime <= timeoutTime) {
      currentTime = millis();
      if (client.available()) {             // если есть байты для чтения
        char c = client.read();             // чтение байта
        Serial.write(c);                    // печать
        header += c;
        
        if (c == '\n') {                    // если байт является символом новой строки
          // если текущая строка пустая — конец HTTP-запроса
          if (currentLine.length() == 0) {
            // HTTP-заголовки ответа
            client.println("HTTP/1.1 200 OK");
            client.println("Content-type:text/html");
            client.println("Connection: close");
            client.println();
            
            // Обработка команд включения/выключения GPIO
            if (header.indexOf("GET /12/on") >= 0) {
              Serial.println("GPIO 12 on");
              output12State = "on";
              digitalWrite(output12, HIGH);
            } else if (header.indexOf("GET /12/off") >= 0) {
              Serial.println("GPIO 12 off");
              output12State = "off";
              digitalWrite(output12, LOW);
            } else if (header.indexOf("GET /14/on") >= 0) {
              Serial.println("GPIO 14 on");
              output14State = "on";
              digitalWrite(output14, HIGH);
            } else if (header.indexOf("GET /14/off") >= 0) {
              Serial.println("GPIO 14 off");
              output14State = "off";
              digitalWrite(output14, LOW);
            }
            
            // Генерация HTML-страницы
            client.println("<!DOCTYPE html><html>");
            client.println("<head><meta name=\"viewport\" content=\"width=device-width, initial-scale=1\">");
            client.println("<link rel=\"icon\" href=\"data:,\">");
            
            // CSS-стили для кнопок
            client.println("<style>html { font-family: Helvetica; display: inline-block; margin: 0px auto; text-align: center;}");
            client.println(".button { background-color: #4CAF50; border: none; color: white; padding: 16px 40px;");
            client.println("text-decoration: none; font-size: 30px; margin: 2px; cursor: pointer;}");
            client.println(".button2 {background-color: #555555;}</style></head>");
            
            // Тело страницы
            client.println("<body><h1>ESP32 Web Server</h1>");
            
            // GPIO 12
            client.println("<p>GPIO 12 - State " + output12State + "</p>");
            if (output12State=="off") {
              client.println("<p><a href=\"/12/on\"><button class=\"button\">ON</button></a></p>");
            } else {
              client.println("<p><a href=\"/12/off\"><button class=\"button button2\">OFF</button></a></p>");
            }
            
            // GPIO 14
            client.println("<p>GPIO 14 - State " + output14State + "</p>");
            if (output14State=="off") {
              client.println("<p><a href=\"/14/on\"><button class=\"button\">ON</button></a></p>");
            } else {
              client.println("<p><a href=\"/14/off\"><button class=\"button button2\">OFF</button></a></p>");
            }
            
            client.println("</body></html>");
            
            // Завершение HTTP-ответа
            client.println();
            break;
          } else {
            currentLine = "";
          }
        } else if (c != '\r') {
          currentLine += c;
        }
      }
    }
    header = "";
    client.stop();
    Serial.println("Client disconnected.");
    Serial.println("");
  }
}

Загрузка и тестирование

  1. Откройте Arduino IDE и вставьте приведённый выше код
  2. Замените REPLACE_WITH_YOUR_SSID и REPLACE_WITH_YOUR_PASSWORD на данные вашей сети Wi-Fi
  3. Выберите плату: Инструменты → Плата → ESP32 Dev Module
  4. Выберите порт: Инструменты → Порт
  5. Загрузите скетч на ESP32
  6. Откройте монитор последовательного порта (115200 бод) и дождитесь появления IP-адреса
  7. Введите этот IP-адрес в браузере вашего смартфона или компьютера
  8. Управляйте светодиодами с помощью кнопок на веб-странице
🔧Совет: Если ESP32 не подключается к сети, проверьте:
  • Правильность ввода SSID и пароля (чувствительно к регистру)
  • Поддержку диапазона 2.4 ГГц вашей сетью (ESP32 не поддерживает 5 ГГц)
  • Стабильность питания платы (рекомендуется 5В через VIN)

Возможные проблемы и решения

  • Веб-страница не загружается:
    • Убедитесь, что устройство подключено к той же сети Wi-Fi, что и ESP32
    • Проверьте корректность введённого IP-адреса
    • Попробуйте использовать другой браузер или устройство
  • Светодиоды не реагируют:
    • Проверьте полярность подключения светодиодов
    • Убедитесь, что резисторы подключены последовательно с анодом
    • Проверьте, назначены ли пины как OUTPUT в коде
  • ESP32 перезагружается:
    • Добавьте конденсатор 10–100 мкФ между 3.3В и GND рядом с платой
    • Используйте стабильный источник питания 5В/2А
