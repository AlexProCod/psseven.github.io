Погодная станция на базе ESP32

Описание проекта: Цель данного проекта — создание погодной станции с использованием микроконтроллера ESP32, которая будет собирать данные о температуре, влажности, давлении и уровне освещенности. Эти данные будут отображаться на экране и могут быть переданы на веб-сервер для удаленного мониторинга. Также возможно создание мобильного приложения для получения этих данных в реальном времени.

Основные компоненты

  1. ESP32 — для обработки данных и подключения к Wi-Fi
  2. Датчик температуры и влажности DHT22 — для измерения температуры и влажности
  3. Датчик давления BMP180 или BME280 — для измерения атмосферного давления
  4. Датчик освещенности (LDR или BH1750) — для измерения уровня освещенности
  5. OLED экран 0.96″ (I2C) — для отображения данных о погоде
  6. Wi-Fi — для отправки данных на сервер или облачное хранилище
  7. Датчик времени (RTC) — опционально, для получения точного времени
💡Совет: Датчик BME280 предпочтительнее BMP180, так как он измеряет не только давление, но и температуру с влажностью — это позволяет использовать один датчик вместо двух.

Шаги реализации

  1. Сбор данных:
    • Используйте датчики для измерения температуры, влажности, давления и уровня освещенности
    • Считывайте данные каждые несколько секунд для актуальной информации
    • Реализуйте обработку ошибок при сбое чтения с датчиков
  2. Отображение данных на OLED экране:
    • Используйте библиотеку Adafruit_SSD1306 для вывода информации
    • Отображайте все параметры в реальном времени с понятной разметкой
    • Добавьте индикаторы состояния (Wi-Fi, ошибки датчиков)
  3. Передача данных на сервер (опционально):
    • Настройте отправку данных на ThingSpeak, Blynk или собственный сервер
    • Используйте HTTP GET/POST запросы для передачи параметров
    • Реализуйте повторную отправку при потере соединения
  4. Подключение к Wi-Fi:
    • ESP32 подключается к сети и передаёт данные в облако
    • Добавьте переподключение при разрыве связи
    • Используйте WDT для защиты от зависаний

Схема подключения

  1. DHT22:
    • VCC → 3.3V
    • GND → GND
    • DATA → GPIO 4
    • Добавьте подтягивающий резистор 10 кОм между DATA и VCC
  2. BME280 / BMP180 (I2C):
    • VCC → 3.3V
    • GND → GND
    • SCL → GPIO 22
    • SDA → GPIO 21
  3. LDR (фоторезистор):
    • Один вывод → 3.3V
    • Другой вывод → GPIO 34 (ADC) и через резистор 10 кОм к GND
  4. OLED экран 0.96″ (I2C):
    • VCC → 3.3V, GND → GND
    • SCL → GPIO 22, SDA → GPIO 21
ℹ️Примечание: Пины GPIO 21 и 22 используются одновременно для BME280 и OLED — это возможно, так как оба устройства работают по шине I2C и имеют разные адреса.

Код для ESP32

Скопируйте приведённый ниже код в Arduino IDE. Замените your_SSID, your_PASSWORD и YOUR_API_KEY на ваши реальные данные.

#include <Wire.h>
#include <Adafruit_Sensor.h>
#include <Adafruit_BME280.h>
#include <DHT.h>
#include <Adafruit_SSD1306.h>
#include <WiFi.h>
#include <HTTPClient.h>

// Настройки Wi-Fi
const char* ssid = "your_SSID";
const char* password = "your_PASSWORD";

// Настройки для датчиков
#define DHTPIN 4            // Пин для DHT22
#define DHTTYPE DHT22       // Тип датчика DHT
DHT dht(DHTPIN, DHTTYPE);

Adafruit_BME280 bme;         // Объект для работы с BME280
#define SEALEVELPRESSURE_HPA (1013.25) // Стандартное давление на уровне моря

// Настройки OLED экрана
#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);

// Настройки LDR
#define LDR_PIN 34          // Пин для LDR (аналоговый вход)

void setup() {
  Serial.begin(115200);

  // Подключение к Wi-Fi
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(1000);
    Serial.println("Connecting to WiFi...");
  }
  Serial.println("Connected to WiFi");

  // Инициализация DHT22
  dht.begin();

  // Инициализация BME280
  if (!bme.begin()) {
    Serial.println("Couldn't find BME280 sensor");
    while (1);
  }

  // Инициализация OLED
  if (!display.begin(SSD1306_I2C_ADDRESS, SCREEN_WIDTH, SCREEN_HEIGHT, &Wire)) {
    Serial.println(F("SSD1306 allocation failed"));
    for (;;);
  }
  display.clearDisplay();

  // Отображение стартового текста на экране
  display.setTextSize(1);
  display.setTextColor(SSD1306_WHITE);
  display.setCursor(0, 0);
  display.println(F("Weather Station"));
  display.display();
  delay(2000); // Задержка перед первым измерением
}

void loop() {
  // Считываем данные с датчиков
  float h = dht.readHumidity();
  float t = dht.readTemperature();
  float p = bme.readPressure() / 100.0F;
  int ldr = analogRead(LDR_PIN);  // Считываем значение с LDR

  // Если считывание не удалось
  if (isnan(h) || isnan(t) || isnan(p)) {
    Serial.println("Failed to read from sensors");
    return;
  }

  // Отображаем данные на OLED экране
  display.clearDisplay();
  display.setCursor(0, 0);
  display.print("Temp: ");
  display.print(t);
  display.println(" C");
  display.print("Humidity: ");
  display.print(h);
  display.println(" %");
  display.print("Pressure: ");
  display.print(p);
  display.println(" hPa");
  display.print("Light: ");
  display.print(ldr);
  display.println(" LDR");

  display.display();

  // Отправка данных на сервер (опционально)
  sendDataToServer(t, h, p, ldr);

  delay(5000); // Задержка между измерениями
}

// Функция для отправки данных на сервер
void sendDataToServer(float temperature, float humidity, float pressure, int light) {
  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;

    // URL для отправки данных (например, ThingSpeak)
    String serverUrl = "https://api.thingspeak.com/update?api_key=YOUR_API_KEY";
    serverUrl += "&field1=" + String(temperature);
    serverUrl += "&field2=" + String(humidity);
    serverUrl += "&field3=" + String(pressure);
    serverUrl += "&field4=" + String(light);

    http.begin(serverUrl);
    int httpCode = http.GET();  // Отправляем GET запрос
    if (httpCode > 0) {
      Serial.println("Data sent successfully");
    } else {
      Serial.println("Error sending data");
    }
    http.end();
  } else {
    Serial.println("WiFi not connected");
  }
}

Пояснение к коду

  1. Wi-Fi подключение: Мы подключаем ESP32 к сети Wi-Fi с помощью предоставленных SSID и пароля
  2. Инициализация датчиков: Мы инициализируем датчики DHT22 для измерения температуры и влажности, BME280 для измерения давления и LDR для измерения уровня освещенности
  3. OLED экран: С помощью библиотеки Adafruit_SSD1306 мы выводим собранные данные на экран
  4. Отправка данных на сервер: Мы используем HTTP GET запрос для отправки данных на сервер (например, сервис ThingSpeak). В запрос включены данные о температуре, влажности, давлении и уровне освещенности
  5. Интервал измерений: Измерения проводятся каждые 5 секунд
❗Важно: Не забудьте установить необходимые библиотеки через менеджер библиотек Arduino IDE: Adafruit Unified Sensor, Adafruit BME280, DHT sensor library, Adafruit SSD1306.

Как собрать

  1. Соединение компонентов:
    • DHT22: Подключите вывод Data к пину GPIO 4 на ESP32
    • BME280: Подключите SDA к GPIO 21, SCL к GPIO 22
    • LDR: Подключите один конец LDR к 3.3V, а другой к аналоговому пину (например, GPIO 34) через резистор 10 кОм к GND
    • OLED экран: Подключите SDA к GPIO 21, SCL к GPIO 22
  2. Настройка сервера:
    • Зарегистрируйтесь на ThingSpeak или другом сервере для мониторинга
    • Получите API ключ для отправки данных
    • Настройте каналы для отображения температуры, влажности, давления и освещенности
  3. Запуск:
    • Загрузите код на ESP32 через Arduino IDE
    • Подключите ESP32 к источнику питания (5В через VIN или 3.3В напрямую)
    • Данные будут отображаться на экране и отправляться на сервер

Возможные проблемы и решения

  • Датчики не определяются:
    • Проверьте подключение SDA/SCL и наличие подтягивающих резисторов 4.7 кОм для I2C
    • Убедитесь, что адрес датчика совпадает с ожидаемым (BME280: 0x76 или 0x77)
    • Проверьте питание датчиков (3.3В, не 5В!)
  • OLED экран не отображает данные:
    • Проверьте, правильно ли заданы размеры экрана в коде (128×64)
    • Убедитесь, что библиотека Adafruit_SSD1306 установлена
    • Проверьте, не конфликтуют ли адреса I2C устройств
  • Данные не отправляются на ThingSpeak:
    • Проверьте корректность API ключа и URL запроса
    • Убедитесь, что канал ThingSpeak настроен и имеет свободные поля
    • Проверьте, что лимит отправки (15 секунд) соблюдён
  • ESP32 перезагружается:
    • Добавьте конденсатор 100–470 мкФ между 3.3В и GND рядом с платой
    • Используйте стабильный источник питания 5В/2А
    • Проверьте, не перегружен ли вывод 3.3В на плате

Идеи для расширения функционала

  • Добавление датчика ветра и дождя: Для полноценной метеостанции
  • Локальное хранение данных: Используйте microSD модуль для записи истории измерений
  • Веб-интерфейс: Создайте локальный веб-сервер на ESP32 для просмотра данных в браузере
  • Уведомления: Настройте отправку предупреждений в Telegram при экстремальных значениях
  • Энергосбережение: Реализуйте глубокий сон (deep sleep) для работы от батареи
🚀Идея: Объедините погодную станцию с автоматикой умного дома — например, закрывать окна при дожде или включать увлажнитель при низкой влажности!
